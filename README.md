# Sales Dashboard

A Streamlit-based sales dashboard for analyzing sales data.

## Features

- CSV upload
- Data preview
- Total sales, average, orders
- Sales by product (bar chart)
- Sales by region (bar chart)
- Filter by region

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy

## How to Run

1. Install dependencies
2. streamlit run app.py
